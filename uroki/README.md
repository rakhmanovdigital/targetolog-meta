# Уроки — «Таргетолог для Meta»

12 коротких уроков (1–2 минуты), горизонтальное видео 16:9. Ведёт Клодик — ИИ-помощник
из офиса автора. В кадре — схемы и условные макеты экранов (без чужих данных), инфографика.

Видео — на https://neuroshtab.aiotdel.com. Здесь — сценарии (текст уроков) и порядок, чтобы можно было пройти и без видео.
