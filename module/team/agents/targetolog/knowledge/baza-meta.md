# База Meta — как устроена система (слой 1)

> Выжимка документации Meta (developers.facebook.com, transparency.meta.com, engineering.fb.com) и
> разборов практиков, октябрь–ноябрь 2026. Главнее — `metod.md`. Help Center Meta меняется — при
> сомнении сверить в браузере.

## 1. Цели и место заявки
- Только цели `OUTCOME_*`: AWARENESS (охват), TRAFFIC (трафик), ENGAGEMENT (вовлечение/сообщения),
  LEADS (заявки), SALES (продажи), APP_PROMOTION.
- **Лид-форма:** LEADS + `ON_AD` + оптимизация `LEAD_GENERATION` (объём) или `QUALITY_LEAD`.
- **Заявка на сайте:** LEADS + `WEBSITE` + `OFFSITE_CONVERSIONS`, нужен пиксель и событие `Lead`.
  Оптимизацию на клики (`LINK_CLICKS`) для заявок не брать — Meta приведёт «кликающих».
- **Директ Instagram:** ENGAGEMENT + `INSTAGRAM_DIRECT` + `CONVERSATIONS`, кнопка «Отправить сообщение»,
  заготовленное сообщение.
- **WhatsApp:** LEADS (или ENGAGEMENT) + `WHATSAPP` + `CONVERSATIONS`; номер привязан к странице.
- **Профиль Instagram:** TRAFFIC + `INSTAGRAM_PROFILE`, кнопка «Перейти в профиль» (подписчики).
- SALES — только если на сайте есть событие покупки с суммой.

## 2. Аукцион и доставка
- Побеждает «общая ценность» ≈ ставка × вероятность действия + качество объявления. Слабый креатив
  дорожает при любой ставке (высокий CPM — сигнал).
- **Andromeda** (с конца 2024) отбирает объявления под человека из огромного числа кандидатов: главный
  рычаг — разнообразие **концепций** креатива. Похожие креативы система склеивает в одно.

## 3. Фаза обучения
- Выход ≈ 50 событий оптимизации за 7 дней на группу; не набирает → «обучение ограничено» (это не
  авария на малом бюджете, но повод не дробить).
- Обучение сбрасывают: правка таргета, креатива, события, ставки, новое объявление, крупная правка бюджета.
  Поэтому первые 2–3 дня не трогаем.

## 4. Advantage+
- Автоматизация Meta: аудитория, размещения, улучшения креатива. Для лидов/продаж включается сама при
  бюджете на кампанию и широкой аудитории.
- Выключать: аудиторию — при жёстком гео/возрасте/особой категории; улучшения креатива — когда ИИ
  искажает факты (цены, сроки, текст на картинке). Охранник по умолчанию выключает искажения креатива.

## 5. Бюджеты и ставки
- Ставка по умолчанию «наименьшая цена» — на малом бюджете ничего другого не ставим.
- Дневной бюджет: в отдельный день до +75%, за неделю ≤ 7× дневного.
- Лимит расходов аккаунта — единственный жёсткий потолок в самой Meta.

## 6. Креативы — форматы
- Лента — 4:5 (1080×1350), сторис/рилс — 9:16 (1080×1920). Можно оба в одном объявлении.
- Безопасная зона 9:16: сверху ~14% и снизу ~35% перекрывает интерфейс — текст туда не ставим.
- Текст объявления: первые ~125 символов видны без «ещё». Заголовок ≤ 40.
- Карусель — 2–10 карточек; видео — первые 3 секунды решают.

## 7. Измерение
- Пиксель + Conversions API (точнее, сервер-сервер). Атрибуция по умолчанию — 7 дней клик, 1 день
  вовлечение, 1 день просмотр.
- Не переливать бюджет в сегмент с самой низкой средней ценой «по разбивке» — система смотрит на цену
  следующего результата. Сравнивать — тестом.

## 8. Качество заявок
- Форма «больше намерений» (экран проверки) — заявок меньше на 20–40%, но чище. Вопросы-фильтры
  (сроки, бюджет, город) отсекают случайных.
- Номер — пусть человек вводит сам (выключить автоподстановку, если Meta предлагает) — меньше «я не оставлял».
- Оптимизация по качеству (Conversion Leads, CRM-события) — когда заявок 100+ в месяц и CRM отдаёт статусы.
