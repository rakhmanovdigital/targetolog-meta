# Словарь — умные слова простыми словами

| Слово | Простыми словами |
|---|---|
| Таргет, таргетированная реклама | реклама в Facebook/Instagram, которую показывают выбранным людям (город, возраст, интересы) |
| Бизнес-портфолио (Business Manager) | «офис» бизнеса в Meta: в нём кабинет, страница, Instagram, доступы людей и роботов |
| Рекламный кабинет (ad account) | «кошелёк + история» рекламы: тут списываются деньги и копится доверие Meta |
| Ads Manager / Meta Ads | программа, где видно всю рекламу: на компьютере — сайт, на телефоне — приложение |
| Кампания | папка верхнего уровня: одна цель (заявки, сообщения, подписчики) |
| Группа объявлений (ad set) | внутри кампании: кому показываем, где, сколько денег в день, когда старт |
| Объявление (ad) | то, что видит человек: картинка/видео + текст + кнопка |
| Креатив | картинка или видео объявления |
| Оффер | что обещаем: «бесплатная консультация», «скидка на первый визит» |
| Связка | оффер + аудитория + креатив, которые вместе приносят клиентов по нормальной цене |
| Дубль (клон) группы | копия группы с теми же настройками, но другими креативами — для честного сравнения |
| Лид, заявка | человек оставил контакт или написал |
| Квал (квалифицированный лид) | заявка от человека, который реально может купить |
| Лид-форма (мгновенная форма) | анкета прямо внутри Facebook/Instagram, без перехода на сайт |
| Заготовленное сообщение | текст, который человек отправит в директ/WhatsApp одним нажатием |
| Кодовое слово | слово в заготовке, по которому видно, с какого объявления пришёл человек |
| Пиксель (набор данных) | счётчик Meta на сайте: видит, кто зашёл и кто оставил заявку |
| Событие Lead / Purchase | сигнал пикселя «оставил заявку» / «купил» — на него учится реклама |
| Conversions API | тот же сигнал, но с сервера сайта — точнее пикселя |
| UTM-метки | хвост ссылки, по которому аналитика сайта видит, с какого объявления пришёл |
| API | способ, которым программы разговаривают с Meta без кликов в браузере |
| Ключ (маркер доступа, токен) | «пароль робота» — с ним охранник собирает рекламу |
| Системный пользователь | робот-сотрудник в портфолио: видит только то, что ты ему дал |
| Охранник | скрипт офиса, через который агент пишет в Meta: держит лимиты, темп, всё на паузе |
| Лимит расходов аккаунта | потолок денег в самой Meta: дошли — реклама встала |
| CPM | цена 1000 показов. Дорого → креатив не цепляет |
| CTR | процент людей, которые нажали. Кликают, но не оставляют заявку → проблема в форме/сайте |
| CPL / цена заявки | расход ÷ заявки — главная цифра |
| Частота | сколько раз один человек видел рекламу |
| Обучение (learning) | первые дни, когда Meta ищет, кому показывать. В это время не трогаем |
| ABO / CBO | бюджет на группу / на всю кампанию. Для тестов — на группу |
| Advantage+ | автоматика Meta: сама подбирает аудиторию, места показа, правит креатив |
| Размещения (плейсменты) | где показывается реклама: лента, сторис, рилс, Facebook, Instagram |
| Библиотека рекламы | открытый архив всей рекламы Meta — смотреть, что крутят конкуренты |
| Особая категория | жильё, кредиты, работа, политика — реклама с ограничениями таргета |
| Модерация | проверка объявления Meta перед показом (минуты — сутки) |
