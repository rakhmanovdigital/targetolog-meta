# Лид-формы — как ставить форму под оффер

> Создание — только охранник: `python3 scripts/meta-launch.py newform <конфиг> <план-формы.json> [--check]`.
> Образец плана формы — `templates/form.example.json`.

## 1. Оффер → своя форма
- Форма продолжает обещание креатива. Креатив «Бесплатная консультация» → заставка формы про консультацию.
- Одна форма = один оффер × один язык (× одна валюта, если в форме есть цены).
- Общую форму «на всё» под конкретный оффер не ставим.

## 2. Как собираем
1. **Тип:** «больше объёма» — дешевле, больше мусора; «больше намерений» — экран проверки, чище.
   Старт — по брифу: дорогая услуга/звонок менеджера → «больше намерений».
2. **Язык формы = язык аудитории группы.**
3. **Экраны:** заставка (заголовок + 1–2 фразы, что получит) → 2–3 своих вопроса-фильтра (варианты
   ответов, не свободный текст) → имя → телефон (или номер WhatsApp — стандартное поле Meta) →
   политика конфиденциальности → «спасибо».
4. **Вопросы-фильтры:** «Когда планируете?» · «Какой формат удобнее?» · «Где вы находитесь?» —
   отсекают случайных. Не больше 3, иначе дорого.
5. **Ключи своих вопросов** — латиницей, коротко (`srok`, `format`, `gorod`). Не называть ключ своего
   вопроса `name`, `phone`, `telefon` — путает выгрузку.
6. **Экран «спасибо»:** что будет дальше и когда («свяжемся в течение часа в рабочее время»), кнопка —
   на сайт / в WhatsApp (`https://wa.me/<номер>?text=<текст>`) / в Instagram.
7. **Порядок:** `newform --check` → показать владельцу заставку, вопросы и «спасибо» → его «да» →
   `newform` → `form <id>` (прочитать обратно) → id в группу плана как `lead_form_id`.
8. **Опубликованную форму править нельзя:** ошибка = новая форма `v2`, старую архивирует владелец.

## 3. Имена
- Форма: `<ПРИСТАВКА>LF_<ОФФЕР>_<ЯЗ>_v<N>_<ГГГГММДД>`. Имя приходит в каждой заявке — по нему видно
  оффер. Латиница, без пробелов, после запуска не переименовывать.

## 4. До включения
- Тестовая заявка: https://developers.facebook.com/tools/lead-ads-testing (делает владелец).
- Проверить, где владелец видит заявку (Meta Business Suite → Мгновенные формы / CRM / телефон) и что
  все поля на месте. Не пришла — группу не включаем.
- То, что обещано в «спасибо» (PDF, расчёт, запись), должно быть готово до включения.

## 5. Если форма не тянет (через 5–7 дней)
- Открытий мало при нормальном CTR → креатив. Открывают, но не отправляют → форма (длинная, страшная).
  Заявки есть, а людей нет → фильтры или тип формы.
- Меняем одну вещь за раз: тип → число вопросов → первый вопрос → заставка. Новая версия — в новую
  группу рядом со старой.
