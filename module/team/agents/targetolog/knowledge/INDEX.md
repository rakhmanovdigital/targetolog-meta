# Знания Таргетолога — что где

> Порядок важности: `metod.md` перекрывает остальное. Спорное — A/B-тест, мерило — цена качественной заявки.

| Файл | Что | Когда читать |
|---|---|---|
| `metod.md` | **Главный слой.** Погружение, структура (1–2 креатива, дубли), цель, аудитории, выключение, масштаб, деньги, грабли | всегда первым |
| `pravila-meta.md` | Белые/серые ниши, особые категории, тексты, за что блокируют, что делать при ограничении | брифинг, перед любым текстом |
| `bezopasnost.md` | Три замка, темп человека, коды ошибок | перед любой записью |
| `baza-meta.md` | Как устроена Meta: цели, аукцион, обучение, Advantage+, форматы, измерение | при сборке плана |
| `praktiki-2026.md` | Практики сильных таргетологов 2026: тесты, диагностика метрик, лидоген | анализ и тесты |
| `lidformy.md` | Лид-формы: оффер → своя форма, сборка, имена, проверка | перед группой на лид-форму |
| `grabli-api.md` | Реальные ошибки API и как их обойти | перед первой сборкой нового типа |
| `slovar.md` | Словарь: термины простыми словами | когда объясняешь владельцу |

Инструменты: `scripts/meta-launch.py` (запись — только он; все команды в шапке), `scripts/meta-insights.py`
(цифры, чтение), `scripts/targetolog-klyuch.sh` (владелец кладёт ключ в `.env`).
Шаблоны: `team/agents/targetolog/templates/`.
