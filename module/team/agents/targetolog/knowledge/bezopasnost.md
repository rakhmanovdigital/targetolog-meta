# Безопасность кабинета и «темп человека»

> Замки зашиты в `scripts/meta-launch.py` — агент их не обходит и не дублирует «вручную».
> Почему банят — `pravila-meta.md` §3.

## Три замка
1. **Meta:** робот (системный пользователь) — роль «Сотрудник», доступ «Управлять кампаниями» только к
   одному кабинету, без финансов; лимит расходов аккаунта ≈ месяц + 10% (ставит владелец).
2. **Офис (охранник):** только кампании с приставкой из конфига · только план с «да» владельца ·
   всё создаётся выключенным, старт завтра · удалять и включать не умеет · дневной потолок ·
   темп человека · ошибка = стоп без повтора · журнал каждого действия.
3. **Владелец:** «да» на план · проверка и включение в Meta Ads · подъём бюджета и потолков.

## Железные правила агента
1. В Meta пишешь только через `scripts/meta-launch.py`. Чтение — `meta-insights.py` / `meta-launch.py status`.
2. Ключ не видишь, не печатаешь, не просишь в чат. Он в `.env` под именем из конфига.
3. Конфиг (`projects/<проект>/targetolog/config.json`: потолки, часы, темп) меняет только владелец.
4. «⛔ СТОП» → не повторяешь, не «чинишь обходом». Читаешь журнал, пишешь владельцу.
5. Верификация / ограничение / «кабинету нельзя рекламироваться» → красная кнопка: никаких записей.
6. Совсем новый кабинет и новый профиль Facebook → предупреди: первые запуски маленькие, без резких
   бюджетов, без пачек; лучше старый кабинет с историей оплат.

## Темп человека (охранник держит)
| Правило | Число |
|---|---|
| Пауза между записями | 20–60 с, с разбросом |
| Перерыв между кампаниями | 10–15 мин |
| Кампаний за запуск / за день | ≤ 3 / ≤ 6 |
| Креативов в группе | ≤ 2 |
| Записей в день | ≤ 150 в день запуска |
| Нагрузка Meta (X-Business-Use-Case-Usage) > 50% | пауза до сброса |
| Ошибка | стоп; ≤ 1 исправленная попытка после правки плана |
| Удаление | никогда — только пауза |
| Проверки validate | редко: серия из ~10 проверок за пару минут даёт лимит (код 17) |

## Коды ошибок Meta (для объяснения владельцу)
| Код | Что значит | Что делать |
|---|---|---|
| 4, 17, 613 с подкодом, 80000–80014 | лимит запросов | охранник ждёт один раз; повторилось — стоп, позже |
| 80005 | лимит запросов к лид-формам страницы | подождать час, формы создавать реже |
| 613 без подкода | защита от злоупотреблений | стоп, владельцу |
| 190 | ключ недействителен | новый ключ (подключение, шаг 9) |
| 10, 200, 294 | нет прав | что-то не выдано или отозвано (подключение, шаг 8) |
| 100 | неверный параметр | разобрать поле, исправить план, ≤ 1 попытка |
| 1885183 | приложение не опубликовано | подключение, шаг 6 |
| 1404163 | кабинету нельзя рекламироваться | красная кнопка |
| 2490427 / 2490468 | объявление отклонено | стоп волны; поправить текст/картинку |
| 3858634 и соседние | нужна верификация рекламодателя для страны | владелец в кабинете, потом id в конфиг |

## Каждый день
`meta-launch.py status` → кабинет активен? оплата прошла? лимит стоит, сколько осталось?
Проблема с оплатой или кабинет не активен → срочно владельцу.
