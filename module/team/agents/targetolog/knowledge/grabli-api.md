# Грабли API — что уже ловили на живых запусках (2026)

> Каждая строка — реальный случай. Проверяй до сборки, а не после «⛔».

1. **Приложение в разработке** → креатив не создаётся (1885183). Публикуем (Live) до первого запуска.
2. **Код языка по памяти** → реклама ушла не на тот язык. Только поиск + `names`; владельцу — названия.
3. **Instagram «пока ничего не назначено»** у робота → объявление от Instagram не собрать. Выдать
   Instagram роботу отдельно. «Теневой» Instagram страницы ≠ настоящий профиль — id брать из `ids`.
4. **Instagram не профессиональный / не связан со страницей** → 2534013.
5. **validate_only кампании не ловит ошибки групп и креативов.** Новое поле группы — сначала
   `addsets --validate-only` на одной группе, потом live.
6. **«Интересное» (explore) Instagram** больше не поддерживается как размещение → охранник режет в check.
7. **Таиланд:** новой группе нужен подтверждённый рекламодатель (3858634); с языком — возраст от 20.
   Сингапур, Тайвань — свои категории; Япония и Корея — без рекламы в WhatsApp.
8. **ЕС/DSA:** для ЕС нужны «бенефициар» и «плательщик» (имя в Библиотеке рекламы); без полей Meta берёт
   значение кабинета по умолчанию — проверь, что там твоё имя/компания.
9. **Особая категория + страны:** страны группы должны входить в список стран категории кампании (2909035).
10. **Лимит лид-форм страницы** (80005): если что-то опрашивает заявки слишком часто — новые формы не
    создаются. Создавать формы, когда опрос не молотит.
11. **WhatsApp-номер** при чтении группы Meta иногда не отдаёт (null ≠ «нет») — первую группу проверить
    глазами в Ads Manager. Чужой номер Meta не пропустит (1487246).
12. **Имена** — только латиница, цифры, `_`. Дефис и пробел охранник не пускает.
13. **Видео:** Meta делает копии видео под новыми id — сравнивать по id нельзя (охранник сверяет иначе).
    Обложку брать кадром с крупным лицом без субтитров.
14. **Время старта — по поясу кабинета**, не по твоему телефону. «Завтра 00:00» охранник считает по кабинету.
15. **Владелец включил группу сразу после создания** → сверка охранника «на паузе» даёт стоп. Это не сбой —
    просто проверь, что всё остальное создано.
16. **Серия проверок подряд** (~10 за 2 минуты) → лимит 17. Проверки по одной, с паузой.
17. **Код 2 «unexpected error»** бывает временным — охранник всё равно стоп; пробуем позже один раз.
