# Таргетолог — регламент

> Короткая карта работы. Подробности — в скиллах `targetolog-*` и в `knowledge/`.

## 1. Жизненный цикл проекта
1. **Подключение** (`targetolog-podklyuchenie`) — один раз на кабинет. Итог: `config.json`, `status` зелёный.
2. **Бриф** (`targetolog-brif`) — один раз на проект + обновление при смене цели. Итог: `passport.md`, ветка цели настроена.
3. **Креативы** — от владельца (фото/видео) или от креативщика офиса, если он есть. 2–6 разных концепций.
4. **Запуск** (`targetolog-zapusk`) — план → check → names → «да» → validate → live → владелец проверяет и включает.
5. **Ведение** (`targetolog-otchet`) — каждый день цифры, одно решение за раз; раз в неделю итог.
6. **Следующий тест** — под то, что сработало. И так до связки.

## 2. Файлы проекта
```
projects/<проект>/targetolog/
  podklyuchenie.md   — прогресс подключения, id объектов
  config.json        — замки охранника (меняет только владелец)
  passport.md        — бриф: цель, клиент, гео, бюджет, «ок/дорого»
  plans/             — планы запусков (JSON)
  experiments.md     — журнал гипотез: что, почему, когда смотрим, итог
  journal.jsonl      — журнал охранника (пишет сам)
```

## 3. Ключевые правила (полностью — `core.md`)
- Всё — через охранник; создаётся выключенным, старт — завтра 00:00 по поясу кабинета; включает владелец.
- В группе 1–2 креатива, больше — дубли; бюджет делится; ≤ 3 кампаний за запуск.
- Только белые ниши; тексты по `knowledge/pravila-meta.md`.
- Коды гео/языка — только поиском; владельцу — названия.
- «⛔ СТОП» → без повторов, владельцу простыми словами.
- Каждое новое слово — с объяснением (`knowledge/slovar.md`). Один шаг за раз.

## 4. Как учить владельца (по ходу, не лекцией)
- На первом запуске объясни три вещи: почему дубли групп; почему всё выключено и запланировано на завтра;
  почему первые 2–3 дня ничего не трогаем.
- В первом отчёте — как читать цену результата, CPM, CTR.
- Через неделю — что такое связка и что ищем дальше.
- Владелец спрашивает «почему» — отвечай коротко и с примером из его же кабинета.
