# INSTALL — инструкция для Клода (Claude Code)

> Этот файл читает Клод, когда человек пишет «установи этот репозиторий» и даёт ссылку.
> Человек, скорее всего, не разбирается ни в рекламе, ни в терминале. Говори просто, по одному шагу.
> Ничего не отправляй наружу, ничего не запускай из скачанной папки — только копируешь файлы.

## 0. Где ставим
- В **корень ИИ-офиса** человека — папка, где лежат `CLAUDE.md` / `AGENTS.md` и `team/`.
- Определи поколение офиса:
  - **Новый** (есть `team/registry.json` и `.agents/skills/`) — сотрудники регистрируются в реестре,
    навыки живут в `.agents/skills/`, копия для Claude делается `scripts/office/materialize.py`.
  - **Старый** (есть `team/map.md`, навыки в `.claude/skills/`, реестра нет).
  - **Нет офиса** — спроси, куда ставить; можно в пустую папку (работает и так).
- Офис под git → сначала снимок: `git add -A && git commit -m "до установки Таргетолога"`.

## 1. Скачать во временную папку
- `git clone --depth 1 <ссылка> <временная папка>` (скретчпад / `/tmp/targetolog-meta`, не внутрь офиса).
- Не получилось → попроси человека: на странице репозитория зелёная кнопка «Code» → «Download ZIP» →
  распаковать → назвать тебе путь.
- **Прочитай `module/` целиком** перед копированием — ты должен знать, что ставишь.

## 2. Скопировать — ничего не перезаписывая
Из `<временная>/module/` в корень офиса, без перезаписи (`cp -Rn <временная>/module/. "<офис>/"`).
Что приедет:
- `team/agents/targetolog/` — сотрудник (core, card, регламент, знания, шаблоны, память);
- `.agents/skills/targetolog-podklyuchenie|brif|zapusk|otchet/` — навыки;
- `scripts/meta-launch.py` (охранник), `scripts/meta-insights.py` (цифры), `scripts/targetolog-klyuch.sh` (ключ).

Уже был `team/agents/targetolog/` или `scripts/meta-launch.py` → не затирай: скажи, что нашёл, и
предложи вариант (поставить рядом как `targetolog-meta`, поправив пути).

### Новый офис (реестр)
1. Навыки: `python3 scripts/office/materialize.py` — он сделает `.claude/skills/` из `.agents/skills/`.
2. Сотрудник: добавь в `team/registry.json` → `agents` объект из `<временная>/install/registry-entry.json`
   (статус `draft`), затем `python3 scripts/office/registry.py render` — перерисует `team/map.md`.
   Вручную `team/map.md` не правь. Проверка: `python3 scripts/office/registry.py validate` → `registry=ok`.
3. Статус `active` — после **пробной задачи**: когда подключение пройдено и `status` охранника зелёный,
   спроси владельца «подтверждаешь, что Таргетолог отработал подключение?» и по его «да» — активация
   штатным `scripts/office/hire.py activate --id targetolog` (evidence: задача «подключение кабинета Meta»,
   артефакт `projects/<проект>/targetolog/podklyuchenie.md`, критерий «ids и status видят кабинет,
   страницу, Instagram», оценка, `confirmed: true`). До этого честно говори «сотрудник в черновике».

### Старый офис (карта)
1. Навыки: скопируй `.agents/skills/targetolog-*` ещё и в `.claude/skills/` (там их ищет Claude).
2. В `team/map.md` одна строка, формат как у соседей:
   `- **Таргетолог** (таргет, реклама, запуск рекламы, что по рекламе) — реклама Meta через охранник API: всё выключено и на завтра, включает владелец; подключение, бриф, отчёты → team/agents/targetolog/core.md`

### Для обоих
- `.gitignore` офиса содержит `.env` (если нет — допиши строку).
- `python3 --version` — нужен 3.9+. Нет → Mac: `xcode-select --install` (окно подтверждения — человек
  жмёт сам) или python.org; Windows — python.org с галочкой «Add to PATH».
- `python3 scripts/meta-launch.py` без аргументов — печатает шапку команд (значит, стоит правильно).
- Временную папку загрузки убери (`rm -r <временная>`), если правила офиса не против.

## 3. Сказать человеку и начать
Своими словами, тепло, коротко:
> Готово — у тебя в офисе новый сотрудник: **Таргетолог**. Он собирает рекламу в Facebook и Instagram
> за тебя. Чтобы он заработал, нужно один раз подключить твой рекламный кабинет — это ~40–60 минут,
> я поведу по шагам: скажу, куда зайти и что нажать, а ты присылаешь скриншот. Начнём?

Дальше — навык `targetolog-podklyuchenie`, потом `targetolog-brif`.
Файл навыка не подхватился автоматически → прочитай его явно по пути `.agents/skills/<имя>/SKILL.md`.

## Обновление («обнови таргетолога»)
1. Скачай свежую версию во временную папку.
2. Можно обновлять: `scripts/meta-launch.py`, `scripts/meta-insights.py`, `scripts/targetolog-klyuch.sh`,
   `.agents/skills/targetolog-*` (потом materialize / копия в `.claude/skills`), `team/agents/targetolog/knowledge/*`,
   `templates/*`, `core.md`, `instruction.md`. Если человек сам правил эти файлы — сначала покажи разницу, его правки важнее.
3. Никогда не трогать: `team/agents/targetolog/memory.md`, `card.md` после активации, всё в `projects/`, `.env`.
